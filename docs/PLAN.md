## Scope and editorial adaptation

The brief is a city introduction, not a commercial venue. No fabricated address, opening hours, prices, booking form, clients, or reviews. The place visit recipe becomes an introduction to London's river; the offer becomes four places to visit. The user explicitly requests a React Flow website path, so its canvas belongs on a separate prototype page. An optional vgpu Tower Bridge study is a separate on-demand 3D experience, not an animated page background.

Stack: Qwik City static generation; Tailwind CSS 3; Utopia fluid type and spacing between 320 and 1440; React Flow isolated through Qwik React. Locale URLs: /zh-tw/ and /en/, default Traditional Chinese. GitHub Pages base: /london-discover/.

Voice: proper nouns and restraint; short geographical descriptions, factual names, direct actions; no jokes, sales claims, invented history, or unverified ticket prices.
